# Mottu Mapping Vision

Aplicação de visão computacional para identificar motos e setores desenvolvido em `python` usando `torchvision`, `yolo`, `easyocr`, `ultralytics`, `requests` e banco de dados `oracle` para fazer a pesistencia.

## Passos para executar

1. Clone o repositorio:

```bash
git clone https://github.com/felipeclarindo/mottu-mapping-vision
```

2. Entre no diretorio:

```bash
cd mottu-mapping-vision
```

3. Configure as variaveis de ambiente conforme o arquivo `.env.example`.

4. Execute a aplicação

```bash
python main.py
```

5. Navegue pelo menu e utilize a aplicação.
