# Mottu Mapping Vision

Computational vision to indentify the motocycles and sectors to post in a database developed `python` using `torchvision`, `yolo`, `easyocr`, `ultralytics`, `requests` and the database `oracle` to make persistence.

## Steps to run

1. Clone the repository:

```bash
git clone https://github.com/felipeclarindo/mottu-mapping-vision
```

2. Enter directory:

```bash
cd mottu-mapping-vision
```

3. Configure the environment variables based with the file `.env.example`.

4. Run the application

```bash
python main.py
```

5. Follow the cli interface to use the application.
